### Etapa B1 — Migração SQL: cardapio_itens (rebuild completo)

SQLite não suporta `ALTER TABLE ... DROP CONSTRAINT`. O rebuild é:

```sql
-- 1. Atualizar dados existentes ANTES do rebuild
UPDATE cardapio_itens SET tipo_refeicao = 'Lanche'
WHERE tipo_refeicao IN ('Lanche da Manhã', 'Lanche da Tarde');

-- 2. Criar tabela nova com CHECK constraint atualizado
CREATE TABLE cardapio_itens_nova (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome_refeicao TEXT NOT NULL,
    tipo_refeicao TEXT NOT NULL,
    CHECK (tipo_refeicao IN ('Lanche', 'Almoço', 'Janta'))
);

-- 3. Copiar dados
INSERT INTO cardapio_itens_nova (id, nome_refeicao, tipo_refeicao)
SELECT id, nome_refeicao, tipo_refeicao FROM cardapio_itens;

-- 4. Trocar tabelas
DROP TABLE cardapio_itens;
ALTER TABLE cardapio_itens_nova RENAME TO cardapio_itens;
```
