## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cozinheira → cliente React | A usuária informa data, alunos, quantidades, medidas e justificativas; esses valores são não confiáveis. |
| cliente React → API FastAPI | O navegador envia Bearer JWT e o payload de refeição atravessa a fronteira de autorização e validação. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Spoofing / Elevation | `PainelCozinha.tsx` e `/refeicoes` | high | mitigate | Usar `fetchJson`/JWT, manter a rota protegida e não aceitar identidade do operador no formulário; a API continua como autoridade de perfil. |
| T-06-02 | Tampering / Repudiation | rascunho de ingrediente e justificativas | high | mitigate | Preservar `item_id`, divergência, quantidade zero para remoção e justificativa por linha no payload; não usar sucesso otimista nem apagar evidência da UI. |
| T-06-03 | Denial of Service / Integrity | efeitos de carregamento e POST | medium | mitigate | Bloquear submissão concorrente, proteger respostas obsoletas, refazer leitura após sucesso/falha e exibir erros de conversão/estoque sem tentar corrigi-los localmente. |
| T-06-05 | Elevation / Tampering | `/conversoes` e editor da cozinha | high | mitigate | Permitir somente GET para cozinheira; POST/DELETE seguem admin-only; o editor aceita apenas `medida_caseira` retornada pela API e nunca recebe peso ad hoc da usuária. |
| T-06-06 | Integrity | escala de receita por alunos | high | mitigate | Exigir alunos antes de exibir/enviar ingredientes, calcular quantidade esperada de forma determinística e fazer o backend comparar/persistir a quantidade escalada antes de deduzir estoque. |
| T-06-04 | Information Disclosure / Tampering | textos vindos de `ApiError` e API | medium | mitigate | Renderizar mensagens como texto React, preservar apenas detalhes acionáveis e não usar HTML injetado. |
| T-06-SC | Tampering | npm/pip/cargo installs | high | mitigate | Não adicionar dependências; confirmar que `package.json`, lockfile e `backend/requirements.txt` não recebem alterações de instalação durante a execução. |
