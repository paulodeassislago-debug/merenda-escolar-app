## ASVS L1 Threat Model

| Boundary | Description |
|---|---|
| browser → first-party public API | A resposta pública contém nomes controlados pelo banco e cruza para o DOM sem autenticação, por desenho. |
| API response → public presentation | Campos técnicos de receita chegam ao cliente e precisam ser filtrados na renderização. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-01-01 | Tampering / XSS | `CardapioPublico.tsx` names from API | high | mitigate | Use `fetchJson`, render names as ordinary React text children, and avoid raw HTML rendering; verify with build/lint and manual long-text input. |
| T-07-01-02 | Information Disclosure | ingredient renderer | high | mitigate | Keep quantity, measure, weight, and recipe metadata in transport typing only; render only the ingredient name or its explicit fallback. |
| T-07-01-03 | Spoofing / Elevation of Privilege | `/cardapio` and `/publico/cardapio` boundary | high | mitigate | Preserve the public route without adding auth, preserve the existing first-party endpoint, and run the anonymous public endpoint regression. |
| T-07-01-04 | Denial of Service | loader/error/retry state | medium | mitigate | Clear transient state before retry, distinguish failed requests from settled empty data, and avoid rendering unbounded layout primitives that cause viewport overflow. |
</threat_model>
