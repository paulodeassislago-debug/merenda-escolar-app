    1. `export function normalizar(s: string): string` — extensão determinística do padrão `normalizarTexto` de `nfe.ts`:
       - lowercase + trim; `normalize('NFD')` + remoção de `[\u0300-\u036f]`;
       - remover pontuação não alfanumérica (`/[^a-z0-9\s]/g` → espaço);
       - colapsar espaços repetidos (`/\s+/g` → `' '`).
    2. `export function tokenizar(s: string): string[]` — `normalizar(s).split(' ').filter(Boolean)`.
    3. `export const ABREVIACOES: Record<string, string>` — dicionário curto (D-21), mínimo:
       ```ts
       {
         musc: 'musculo', bov: 'bovino', bovina: 'bovino',
         frango: 'frango', suino: 'suino', suína: 'suina',
         cong: 'congelado', congelado: 'congelado', kg: 'kg', l: 'l',
         pac: 'pacote', pct: 'pacote', cx: 'caixa', un: 'unidade',
       }
       ```
       (as chaves já normalizadas; expanda livremente com termos comuns de merenda escolar — a expansão é da liberdade do executor, mantendo o formato `normalizado: expandido`).
    4. `export function expandirTokens(tokens: string[]): string[]` — mapeia cada token via `ABREVIACOES` quando existir (retorna o token original quando não existir; compara a chave já normalizada).
    5. `export interface ScoreSimilaridade { score: number; motivo: string; }` e `export function similaridade(a: string, b: string): ScoreSimilaridade`:
       - tokeniza a e b, expande abreviações de ambos;
       - score = (tokens comuns) / (max(tokensA, tokensB)) com match por token expandido (case-insensitive já normalizado); score 0 se qualquer lado vazio;
       - motivo legível: se todos batem → `"Todas as {N} palavras batem"`; senão → `"{K} de {N} palavras batem"` (K = comuns, N = maior lado); se nenhuma → `"Nenhuma palavra coincide"`.
       - Regra determinística: mesma entrada → mesmo score.
